# Azentrius design reference

The active reference is the complete, unmodified tree in **upstream-edd4c67/**,
from [Azentrius/design-system](https://github.com/Azentrius/design-system/tree/edd4c67da6d7c606296c3bbd13d7aa5da548f452).
`UPSTREAM.json` records its origin. `UPSTREAM.sha256` contains SHA-256 checksums,
with paths relative to this directory. Every file was also checked against its Git blob.
No upstream script was executed, and no change was made to the design-system repository.

The maintainer explicitly requested this read-only copy and the restoration of older
references for this change. The historical `upstream-9ed4032/`, `upstream-eb827c8/`,
`upstream-ab59a45/` and original package files were restored unchanged from application
commit `394bc23`. They are evidence, not the active design specification.
`PACKAGE.sha256` continues to describe the original package.

Upstream text, licenses, assets and source files retain their original language and bytes.
They are not authored application documentation and are not relicensed as Apache-2.0.
See each snapshot's LICENSE and LICENSES, and the application NOTICE.
Do not edit snapshots: report gaps to the maintainer for resolution in the design system.

The application audit, deliberate exceptions and validation are in
[docs/DESIGN_SYSTEM.md](../../../docs/DESIGN_SYSTEM.md).
