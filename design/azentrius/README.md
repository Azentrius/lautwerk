# Azentrius design reference

The reference is the complete, unmodified tree in **upstream-94009ab/**,
from [Azentrius/design-system](https://github.com/Azentrius/design-system/tree/94009ab6e4b1ef895aeac324fa98989e17ce863e)
at commit 94009ab (18 October 2026), after the move to azentrius.com.
`UPSTREAM.json` records its origin. `UPSTREAM.sha256` contains SHA-256 checksums of its 155 files,
with paths relative to this directory. Every file was also checked against its Git blob.
No upstream script was executed during the import.

The design audit in [docs/DESIGN_SYSTEM.md](../../docs/DESIGN_SYSTEM.md) was made against design-system
commit edd4c67 for 0.1.18. Changes after edd4c67 (among other things the Android section, the Android
Auto section, the tokens and the licence headers of the `ic_az_*` icons) are not yet audited for the
application; the rename to Lautwerk adopted only the parts that concern the name, the word mark and
the app icon files.

Earlier snapshots (`upstream-edd4c67/`, `upstream-f2c9df4/`, `upstream-9ed4032/`, `upstream-eb827c8/`,
`upstream-ab59a45/`) and the original package files were removed from the working tree on 18 October 2026.
They remain in this repository's Git history; the last commit that contains them is `2454482`.

Upstream text, licenses, assets and source files retain their original language and bytes.
They are not authored application documentation and are not relicensed as Apache-2.0.
See the snapshot's LICENSE and LICENSES, and the application NOTICE.
Do not edit the snapshot: report gaps to the maintainer for resolution in the design system,
then import a new snapshot.
